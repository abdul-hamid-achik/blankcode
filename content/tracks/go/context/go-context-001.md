You are asking a model to write one struct literal:

> Construct the `client.Config` for region `us-east` with a retry budget of
> three.

It has never seen this codebase. Left alone it will write
`client.Config{Region: "us-east", Retries: 3}` — the field names any Go
project *would* use, which is exactly why they feel safe to guess. This
project used `RegionCode` and `RetryBudget`, and the guess is a compile
error you get after the model has confidently explained its code.

Four things could be shown to it. Each costs what it costs:

| source | tokens |
| --- | --- |
| The Config type definition | 200 |
| An example from another service | 1100 |
| The team Go style guide | 2200 |
| The generated client mocks | 4500 |

Pick what to hand over, then write the literal. You are scored on being
right, and separately on what it cost.

## Tests

```go
package main

import (
	"strings"
	"testing"
)

// This exercise is not graded by running the learner's code. It is graded
// by the context-selection service: what they chose, what it cost, and
// whether the answer was accepted.
//
// These tests keep the exercise's own definition honest — the definition is
// the thing that decides whether the exercise measures anything.

func TestSolutionUsesTheRealFieldNames(t *testing.T) {
	for _, needed := range []string{"RegionCode", "RetryBudget", "us-east", "3"} {
		if !strings.Contains(answer, needed) {
			t.Fatalf("the reference answer must contain %q, got: %s", needed, answer)
		}
	}
}

func TestSolutionAvoidsTheGuessableNames(t *testing.T) {
	// "Region:" and "Retries:" are the fields any Go project would use —
	// which is why they are the trap, and must not appear in the reference.
	for _, guess := range []string{"Region:", "Retries:"} {
		if strings.Contains(answer, guess) {
			t.Fatalf("the reference answer must not use the guessable %q", guess)
		}
	}
}

func TestAnswerIsAStructLiteral(t *testing.T) {
	if !strings.Contains(answer, "client.Config{") {
		t.Fatalf("expected a client.Config literal, got: %s", answer)
	}
}
```

## Solution

```go
package main

// The type definition (200 tokens) is the only source that STATES the
// field names — RegionCode and RetryBudget, not the guessable
// Region/Retries. The example contains them too, five times the price and
// wrapped in another service's plumbing; the style guide and the mocks
// never name a field at all.
var answer = `client.Config{
	RegionCode:  "us-east",
	RetryBudget: 3,
}`
```
